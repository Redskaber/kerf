## 勘误实录（规程记忆——下轮直接避坑）

1. **弱内容等共享快路径不健全**：def⊆use 顶层角使 target == use ==
  新节点 scopes → 共享过早触发（展开代次不提升——parity 套件捕获
  my-or/swap! 分歧）——快路径必须有**构造方证书**（uniform_tag/
  uni 标记），内容巧合不可作证据；
2. **python str.replace 静默未匹配**：cargo fmt 重排代码块后搜索串
  失配——替换未发生但流程继续（打印「updated」误导）→ 协议错配全
  崩（5 头 krf vs 6 头桥）；教训：**结构化编辑用 Edit 工具（匹配
  失败显式报错）**，脚本替换后必须 rg 验证关键标记存在；
3. **include_str! 嵌入源**：krf 编辑后必须重建二进制——旧二进制跑
  旧嵌入源（「编辑了却还是旧行为」的第一嫌疑）；
4. 深度上限变更的全域同步面：种子 expander / 自举 expander.krf /
  负例矩阵 / **门审计期望消息**（stage1 两处 500 漏网——本轮补齐）
  ——数值类口径变更须 grep 全库数字；
5. 后台进程在本沙箱被工具会话拆卸回收（setsid 亦无效）——长任务须
  前台分窗运行或根治其成本。
