## 语言（用户可见）能力

**支持**：9 核心原语 / let let* letrec cond and or when unless while /
define-syntax + syntax-rules（含省略号）/ quote（字面量与列表点对）/
quote 符号（`(quote sym)` → 符号值；eq? 按名相等——r5 TD-002）/
48 内置函数（算术/比较/序对/列表操作/谓词/I/O/字符串——r5 标准库最小集）/ 词法闭包（可变捕获）/
递归（迭代式 VM 帧，深度 10^5）/ module 形式（单模块）/ 行注释与嵌套块注释 /
Unicode 标识符（NFC 归一）/ `'x` 引号简写

**显式不支持（报错而非静默）**：quote 向量 / 尾调用优化 /
字符串 < 比较 / 闭包作为序对元素 / define 非头部位置 / 非 bool 条件 / 符号值参与算术与比较（类型严格）
