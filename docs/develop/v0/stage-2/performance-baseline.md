**漂移归因（TD-028——三候选，profile 定锚前不定论）**：
1. r25 效应两操作码 + r30 FFI 三操作码入 VM 主分派 match（46 臂分支布局变化）；
2. GC 六来源入口（r25 continuation 帧链——零活跃 continuation 时仍过入口检查）；
3. ForeignBox 装箱追踪器入口（TD-010 r24 同型）。

**判定依据**：正确性零影响（758:0:0 + 四审计集 190 case + fixpoint 维持）；§14.5.3 D6 条款「性能瓶颈除非影响功能正确性，否则记录为 Stage N+2 优化项」；漂移量级用户不可感知（CLI bench 口径）。

| 面 | 复杂度 | 证据 | 判定 |

## 5. 复测协议

- 每轮代码变更后：CLI bench 双基准（fib + gc_tail）单发复测（±5% 噪声带判定）；
- 每批次末：三重采样（本文件口径）+ 全量测试 wall 记录；
- 大阶段末：clean 起步全量重建 + 二进制尺寸 + 与上表逐行对比；
- 漂移超噪声带 → 当轮 TD 登记（R2 纪律——r36/TD-028 先例）。
