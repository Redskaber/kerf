## 3. 管道流程审查

- **中间表示必要性**：Stx → CoreExpr → (IrGraph/CodeValue) → Bytecode 四级——各级有独立消费者（展开卫生/静态分析/后端 lowering/VM 执行），无「不必要的中间表示」。
- **回流/回查反模式**：单向流机械验证（§11 七项——见 architecture-review §2）；compile 不回查 reader；VM 不回编 compiler。
- **缓存回流**：CompilerKind 分桶（种子不查不存实测 r23）——缓存键正确性经内容寻址 + NIST 向量锚。
