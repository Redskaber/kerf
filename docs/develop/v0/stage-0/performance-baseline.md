## 7. 口径说明（必读——防跨轮数字误比）

1. **bench 内置计时**：`cmd_bench`（src/main.rs:260）先跑 1 次**验证轮**（打印"验证：⇒"），再对 N 轮计时取均值。每轮 = 完整 `run_source` = **读取 + 编译（reader→expander→compile 全前端）+ fib(25) VM 执行**，**不含**进程启动。故"每轮 88.8ms"是"编译+执行"整程，非纯 VM 执行。
2. **外部 time**（`date +%s%N` 差分）：含进程启动（本机约 1-2ms）+ 上述整程。`kerf run` 单程 89ms ≈ 内置 88.8ms + 启动——两口径互洽 ✅。
3. **`bench N` 的外部时间 ≈ 启动 + (N+1) × 每轮**（多 1 个验证轮）：`bench 1` 外部 ~180ms = 启动 + 2×88.8ms，自洽 ✅。
4. **GC 压力口径**：gc_stress.krf 每轮 3×10^5 对象分配（spin 30000 × 10 cons）——r1 文档 0.72s 为陈旧/口径混合夸大值（T14-d 裁定更正为单轮 ~0.17s）；本表与 0.17s 同口径可比。
5. **测试耗时口径**：13.6s 含 release 测试目标**编译**；1.33s 为二进制缓存后的纯执行。两口径分别对应"clean 验收"与"日常回归"场景。
6. **环境声明**：单机顺序执行、无并行负载、同日同会话；跨会话（跨天）比较时按 ±5% 环境噪声预留。
