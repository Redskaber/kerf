## 4. 管道流程审查（§14.6.2 项 3）

- **单向无回流**：read → expand → lower → compile → vm → runtime 单向（§11 五项 grep 全 PASS——36-a D1）；**无「回查」反模式**（编译器不回读 reader 状态；VM 不回写编译器）。
- **中间表示必要性**：Stx（相位分离载体——非冗余）/ CoreExpr（归约对象——06 语义层）/ IrGraph（⚠️ TD-015：run/eval 路径计算后旁路——**唯一观察项**，O(n) 非热点，按消费方拆分入口的偿还计划在案）/ Bytecode（VM 输入）——四层各有语义角色，无「不必要的中间表示」。
- **分流出口收敛**：compile_front 单一逻辑 → 生产（自举）/ 种子（引导+oracle）两出口——设计上消除了「双管线漂移」的回流风险。
